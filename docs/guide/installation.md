# Installation

## TypeScript library

```bash
npm install variant-api
```

```bash
bun add variant-api
```

## MCP server

```bash
npm install -g variant-mcp
```

Or run it with `npx`:

```bash
npx -y variant-mcp
```

## API key

Set the upstream API key as an environment variable:

```bash
export VARIANT_API_KEY=your-key-here
```

The MCP server also accepts `--api-key`.
