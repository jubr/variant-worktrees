A resolver pointed at a directory that is not a git checkout does the same. `variant --version` from source on this branch prints the package version, a hyphen, `{slug}-{n}-{hash4}`, that platform token for the runtime, the UTC date of the run, and that URL, with no hash in the parentheses. The lines above the version line are the cursive drawing. `variant --help` still starts with `variant v` plus the package version, with no drawing and with neither the URL nor parentheses. `variant -v` does not print the version line. Verify `bun test packages/variant-cli/test/version-line.test.ts packages/variant-cli/test/cli.test.ts` fails first.
