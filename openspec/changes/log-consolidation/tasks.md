- [ ] 1.1 Add failing tests in `packages/variant-cli/test/log-level.test.ts` for [specs/variant-cli/logging | Log level flag](../../specs/variant-cli/logging/spec.md#requirement-log-level-flag) and [specs/variant-cli/logging | Verbose is not a log level](../../specs/variant-cli/logging/spec.md#requirement-verbose-is-not-a-log-level). The contact warning on a default `variant list` starts with `[warning]` on stderr and stays off stdout. `--log-level=error` hides it and exits 0. `--log-level=trace` prints a line that starts with `[trace]`. `--log-level=debug` before the command name selects debug. `--log-level=warning` selects warn. `--log-level=loud` still exits non-zero, names the flag and the allowed values, and does not run the command. `variant list -v` stays the verbose listing and does not print a line that starts with `[debug]`. An info event `listed variants` prints `[info] listed variants`. An info event `[demo] [provision] create schema app` prints `[info] demo [provision] create schema app`. With stderr a terminal and `NO_COLOR` unset, `[create] + mise install` at info is dark-gray `[`, green `info`, dark-gray `]`, reset, cyan `create`, reset, then ` + mise install`. With stderr not a terminal, or with `NO_COLOR` set (including empty), a warn line starts with `[warning]`, contains the message, and has no ANSI sequence. Trace, debug, warning, and error use gray-blue `38;5;67`, yellow `33`, orange `38;5;208`, and red `31` on the level word. Verify the new assertions fail first.
